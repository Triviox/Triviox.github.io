Politica de Privacidad

1. Alcance

Aplicacion de uso personal y privado. El unico usuario autorizado es su titular, Diego Fernando Vilas Ancheta. No existe registro de usuarios ni acceso para terceros.

2. Datos a los que accede

Con el consentimiento explicito del titular, la aplicacion accede a sus propias cuentas de Google: Drive, Google Docs, Google Sheets, Gmail, Google Calendar, Google Tasks, Contactos y YouTube. Los permisos se limitan a lo necesario para leer, crear, modificar y enviar contenido propio.

3. Donde se almacenan los datos

La aplicacion no tiene servidores propios ni base de datos remota. Los datos se procesan en el propio dispositivo del titular. Las credenciales de acceso (client secret y token de refresco) se guardan unicamente en el almacenamiento local del dispositivo, con permisos restringidos, y no se transmiten a terceros.

4. Cesion a terceros

No se venden, alquilan, comparten ni transfieren datos a terceros. No se usa publicidad ni analitica de terceros. El acceso a las API de Google se realiza directamente contra los servidores de Google, sin intermediarios.

5. Uso limitado

El uso de la informacion recibida desde las API de Google se limita a las funciones descritas y cumple la Politica de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

6. Conservacion y eliminacion

El titular puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions y eliminar las credenciales locales borrando los archivos de token del dispositivo. Al revocar el acceso, la aplicacion deja de poder consultar o modificar datos de forma inmediata.

7. Seguridad

Las credenciales se almacenan con permisos de archivo restringidos y el acceso al dispositivo esta protegido por bloqueo de pantalla. No se registran datos sensibles en texto plano fuera del dispositivo.

8. Cambios

Cualquier cambio en esta politica se publicara en esta misma pagina.
